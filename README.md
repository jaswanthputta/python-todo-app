# Python To-Do List App

A simple command-line task manager built using Python. It allows users to add, view, and delete tasks while saving them locally in JSON format.

## Features
- Add new tasks
- View all saved tasks
- Delete tasks by number
- Automatically save tasks
- Load saved tasks when the application starts
- Handle invalid menu input

## Technologies Used
- Python
- JSON
- pathlib
- Git and GitHub

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run:

   `python main.py`

## Project Structure

- `main.py` — application logic
- `tasks.json` — local task storage, generated automatically
- `.gitignore` — excludes local task data and unnecessary files
- `README.md` — project documentation

## Learning Outcomes

Practised Python functions, lists, loops, file handling, JSON serialization, exception handling, and Git version control.
